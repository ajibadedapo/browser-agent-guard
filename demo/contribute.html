Contribute a session

The detector is tested against real recorded sessions. You can add one by doing a short task on this page, by hand or with a browser agent.

What is recorded

  • Pointer positions and times, clicks and the size and position of what was clicked.
  • When keys were pressed, and whether each was a character key or a shortcut, but never which key.
  • How long each field's content is, never the content itself. Password and autofill fields record no length.
  • Scrolling, pasting and whether each event came from real input.
  • Whether the browser reports that it is automated.

Nothing leaves your browser. There is no server. You review the exact file before you download it, and you decide whether to submit it.
